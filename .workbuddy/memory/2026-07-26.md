# 2026-07-26 工作日志

## v1.5.3 — 重构编码器检测为硬件+测试双层验证

- 修改 `core/hw_detect.py`：
  - `HardwareInfo` 新增 `encoder_hw_status` 和 `encoder_test_results` 字段。
  - 新增 `_has_nvidia_hw()`：检查 `/dev/nvidia*` 和 `nvidia-smi`。
  - 新增 `_has_intel_qsv_hw()`：检查 `/dev/dri/renderD128`、`/dev/dri/card0`、`vainfo`、Intel vendor `0x8086` 及 GPU 型号。
  - 新增 `_has_amd_amf_hw()`：检查 `/dev/dri` vendor `0x1002`、`lspci` 及 GPU 型号。
  - 新增 `_has_mediacodec_hw()`：仅在 `is_mobile` 时返回 True。
  - 新增 `_test_encoder()`：用 `ffmpeg -f lavfi -i color=c=black:s=2x2:d=0.04 -c:v {enc} -f null -` 进行 5 秒短编码测试。
  - 重写 `_detect_ffmpeg_encoders()`：
    - 第一步：ffmpeg `-encoders` 列表检查声明支持。
    - 第二步：硬件检测生成候选列表，排除无硬件的编码器。
    - 第三步：对候选编码器逐个运行 ffmpeg 测试，返回码 0 才加入 `available_encoders`。
    - `libx264` 始终作为 CPU 兜底，无需硬件检测。
    - 所有步骤带 try-except，ffmpeg 未安装时输出 ERROR 日志。
  - `log_summary()` 新增 `编码器硬件状态` 和 `编码器测试结果` 输出行。
  - 新增 `_format_encoder_hw_status()` 和 `_format_encoder_test_results()` 辅助方法。
- 更新 `metadata.yaml` 版本号为 `v1.5.3`，更新 `CHANGELOG.md`。
- 已通过 `py_compile` 语法校验；在 Windows 环境用 stub logger 测试，ffmpeg 未安装时正常输出单次 ERROR 日志。

## 补充 — 硬件检测新增操作系统版本检测

- 修改 `core/hw_detect.py`：
  - `HardwareInfo` 新增 `os_name` 和 `kernel_version` 字段。
  - 新增 `_detect_os()` 方法：
    - Linux 优先读取 `/etc/os-release`，解析 `PRETTY_NAME` / `NAME` + `VERSION_ID`。
    - 若 `/etc/os-release` 不存在或解析为空，回退到 `lsb_release -ds`。
    - Windows 回退到 `platform.platform()`，macOS 回退到 `macOS {ver}`。
    - 内核版本使用 `platform.release()`。
  - `detect()` 中增加 `await self._detect_os()`，确保在日志开头输出。
  - `log_summary()` 在检测结果开头输出 `操作系统: ...` 和 `内核版本: ...`。
- 版本号不变，保持 `v1.5.2`。
- 已通过 `py_compile` 语法校验；/etc/os-release 解析逻辑已用样例验证。

## v1.5.2 — 修复 ffmpeg 编码器检测正则

- 修改 `core/hw_detect.py` 中 `_detect_ffmpeg_encoders()`：
  - 原正则 `V\.\.\.\.\s+encoder` 只匹配 `V` 后 4 个点，但 `ffmpeg -encoders` 输出前缀为 1 位类型 + 5 位标志（如 `V....D`、`V.....`）。
  - 修正为 `V[\.\w]{5}\s+encoder`，可正确识别 libx264 / h264_nvenc / h264_qsv / h264_amf / h264_mediacodec。
  - 已用用户提供的 ffmpeg 7.1.5 输出样例验证，可正确匹配 libx264、h264_nvenc、h264_qsv。
- 更新 `metadata.yaml` 版本号为 `v1.5.2`，更新 `CHANGELOG.md`。
- 已通过 `py_compile` 语法校验。
